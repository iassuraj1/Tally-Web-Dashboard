How to Add Users

Use this guide from Settings > Users & Roles > Users.

Add a User

  1. Open the Users tab.
  2. Click Invite User to add a team member.
  3. Enter the registered email address of the person you want to add.
  4. Choose a role and review the permissions shown under the invite form.
  5. Click Send Invite.

Choose the Right Role

Admin

Full access to company settings, users, vouchers and reports.

Accountant

Voucher entry, reports and export access for accounting work.

Viewer

Read-only access for reports and basic review work.

Invite Accountant

Use Invite Accountant when you want to add a bookkeeper, CA, auditor or finance team member. The invite form opens with the Accountant role selected, and you can still adjust permissions before sending.

Invite User

Use Invite User for any other staff member. Select the role that matches the user's responsibility before sending the invite.

After Inviting

The invited person must already have an account with the same email address. If the email is not registered, ask them to sign up first, then send the invite again.

You can later change the user's role, disable access, or remove them from the same Users tab.
